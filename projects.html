Project

Network Monitoring System

Problem

Many small and medium-sized organizations lack an affordable solution for monitoring network devices in real time.

What I Did

I designed and developed a web-based Network Monitoring System using Flask and Python. The application monitors device availability, CPU usage, memory utilization, bandwidth, and uptime while displaying the information on an interactive dashboard.

Technologies Used
Python Flask SQLite HTML Bootstrap JavaScript
Key Features
  • Real-time device status monitoring
  • CPU and memory utilization tracking
  • Bandwidth monitoring
  • Device uptime monitoring
  • Interactive dashboard
  • Automatic device alerts
